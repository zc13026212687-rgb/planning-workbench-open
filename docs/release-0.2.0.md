# 0.2.0：地块、指标、图则与 MCP

本版把道路与断面教学引擎扩展到控规地块生成、指标计算和可编辑图则。新代码位于独立源码副本，原有引擎和用户原图保持独立。

## 本版新增

- `/regulatory` 本地操作页：载入参数、调道路总宽、点击地块编辑指标、总图/图则切换、面积平衡和错误提示、成果 ZIP，以及可选 CAD 新图落图。修改参数后标明预览过期，先重新计算再导出。
- `app/parcels.py`：有孔洞的边界、道路计算走廊并集切分、用户地块检查、面积和比例、容积率/密度/绿地率条件计算、图则生成、原生 DXF 与 CSV/JSON 导出。
- 地块几何绑定：指标归属与几何摘要关联；原绑定与新几何不符时产生阻断错误。重新绑定要求调用端先让使用者核对当前地块，不能默默丢弃旧绑定。
- CLI：增加 `validate --spec`、地块 `generate --spec` 和 `sheet --spec --parcel --out`。生成结果保留原始参数和校核信息。
- `planning_mcp.py`：四个实际 stdio 工具支持案例读取、校核、导出和单地块图则。协议错误与工具失败分别返回，错误后服务继续；没有任意命令、网络 URL 或 Python 执行入口。
- `planning-cad-regulatory-suite`：新增技能；安装器支持 `--only` 及可选 `--python`，不修改未选择的技能。
- 发布白名单更新：包含新操作页、MCP、例子和说明，重新生成版本化文件清单，排除个人路径与运行资料。

## 可复算的教学例子

默认例子 `examples/regulatory-parcels.json` 是原创 240×180 米边界，带 30×30 米孔洞；两条计算道路总宽分别为 20 米和 16 米。有效边界面积 42300 平方米，道路并集面积 7120 平方米，四个地块合计 35180 平方米，面积平衡残差为 0。这里的参数和用途代码均为合成教学假设。

例子不是大钟寺真实场地。将它用于真实项目之前，必须换成已核实的测绘坐标、道路条件与控制指标。保留孔洞只表示从计算范围排除某块空间，不自动推断权属、保护身份或可建设性。

网页 ZIP 默认包括总图 DXF、指标 CSV、地块 JSON、参数、质量报告和四张图则；输入地块数变化时按实际数量生成。图则采用原创 A3 横向图框，模型空间以米表达 0.420×0.297 米纸张尺寸；图内地块按注明比例缩放，不能视为原坐标测绘几何。

## 验收方法与限制

运行 `python -m pytest -q` 检查几何、绑定、CLI/API 和协议回归。MCP 测试使用真实子进程 stdin/stdout 和 DXF 回读；自动测试不会启动真实 AutoCAD。实际 CAD 落图、字体、打印和用户可见状态需单独检查，不从单元测试通过推定。

本轮开发验收记录为 328 项 pytest 通过，覆盖新增地块、API 和 MCP 检查；另在真实 AutoCAD 2025 中完成总图 14 个实体、P001 图则 20 个实体的落图，检查重复操作幂等、撤销/重做写入、保存与重新打开；总图回读为 14 个实体、INSUNITS=6。浏览器中已实测道路总宽改为 22 米，以及指标几何绑定失配时阻断。该记录限于本次案例与环境，不能外推为全部真实项目已验证。

CAD 默认关闭；网页或 MCP 的新图写入需明确授权参数，CLI 需 `--cad-new`。只对本引擎新建的图纸写入。导出成功和 CAD 保存成功分别记录；发生中途失败时保留诊断文件及实际状态。

本版仍未实现真实地形与纵断面、复杂自动选线、完整管线与土方、完整法定控规审查、自动认定指标合法性、其他 CAD 厂商全适配。本次功能调查也未形成商业产品运行结果逐项对照，不能据此声称等价替代、完整复刻或性能超越。
