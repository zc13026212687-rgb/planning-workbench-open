# 清规AI：独立实现与开源范围

本工程围绕“明确输入 → 几何计算 → 指标校核 → 可编辑成果”的控规教学需求编写原创实现。计算使用公开数学操作与开源依赖；功能需求可以来自规划工作流程和本机界面观察，具体代码、交互样式与教学图框由本工程独立编写。

## 已有证据与未完成的比较

本轮对用户本机安装程序进行只读菜单清点，记录到 19 个顶层菜单、900 个菜单宏定义和 924 个菜单挂接。这三个数是静态界面结构计数：同一命令可以重复挂接，宏可能调用子命令，也可能依赖当前 CAD 状态。因此它们不是 900 个独立功能，更不是本工程已经实现的功能数量。

公开源码只保留本段概要与原创功能映射，不包含提取的商业菜单文件、整本操作手册、二进制程序、界面图标、注册信息或破解材料。本轮没有完成商业产品各项命令的运行对照，没有可靠依据判断行为完全等价或性能胜出。

## 实现映射

| 规划任务 | 本项目实现 | 当前边界 |
|---|---|---|
| 道路中心线成路 | 解析偏移、独立真圆弧、限定同标高 T/X 路口 | 不支持任意复杂路口、自动选线或完整施工设计 |
| 道路横断面 | 组成宽度、两侧向外横坡、局部基准高程累加 | 无真实地形、纵断面、缘石结构层、土方与管线 |
| 道路切分地块 | 边界/孔洞、多道路走廊并集、差集与编号 | 走廊是几何计算对象，不自动成为已批红线 |
| 用户地块检查 | 越界、重叠、孔洞、未分配面积、面积平衡 | 不能根据几何确定产权、合法用途或保护身份 |
| 控制指标计算 | 净面积、容积率条件面积、密度/绿地率条件面积 | 指标由用户提供；不自动套用法定数值或填补未知值 |
| 指标归属 | 几何摘要绑定，变化时阻断并要求核对 | 编号相同不证明地块相同，不能自动移植旧指标 |
| 图则与成果 | 原创 A3 图则、可编辑 DXF、CSV/JSON、参数/QA | 尚非完整审批图集；图则内几何为注明比例的缩放示意 |
| CAD 连接 | AutoCAD ActiveX，新建独立图纸、绘制、回读、保存 | 真实目标环境须验收，不向用户既有原图任意写入 |
| AI 调用 | Skill、CLI、四工具 stdio MCP | 模型负责解释与调用，几何和检查由引擎执行 |

## 参数与数据血缘

每份可交付成果应保留 `spec`、参数来源、单位和坐标语义、质量报告及对应实体。米制局部坐标不等于已经地理配准。输入经纬度、无比例图片或未知单位 CAD 时，先建立可核实的转换依据；缺少依据时只进行明确标识的示意工作。

道路与地块模块各有几何范围。地块切分使用走廊面积，不提供与道路平面引擎完全相同的路口圆角。需精确路口时先形成经过核查的道路面，再由相应输入接口或人工流程核实衔接，不把两种简化结果混为一张工程图。

示例数据全部为 synthetic。用户资料、课程卫星底图、图库 DWG 和法定规划文本应在私有工作区单独管理；能在本机读取不意味着可以随源码再分发。对外报告区分源码功能、测试通过、真实 CAD 验收和规划审查四种状态。

## 公开包边界

MIT 覆盖本项目自有代码、原创图框、合成例子和技能说明，依赖许可证另行遵守。公开包内容由 `build_release.py` 白名单决定：引擎、原生操作页、桌面源码、技能、例子、测试与必要文档。公开标准仅提供出处链接和自有条目解释。

以下内容保持在公开包外：本机数据与访问配置、用户绝对路径、旧清单、`.venv`、`node_modules`、`data`、`evidence`、编译产物、商业软件及提取物、许可证/注册信息、原始教学或测绘资料。技能安装后的 `local-engine.json` 为当前电脑定位引擎，只留在本机。

打包会回读压缩包并核对 SHA-256。这证明文件传输与所选源码一致，不证明全部功能与第三方软件等价，也不证明规划成果符合审批条件。正式 GitHub 发布属于单独操作；当前工程只生成可供审查的本地源码包。
