# 清规AI · PlanningWorkbench Open 0.2.0：Windows 便携发行

这次发行解决源码版需要另外安装 Python、构建网页，以及技能和桌面入口分散的问题。产品统一显示为“清规AI · PlanningWorkbench Open 0.2.0”，保留原有 CLI、MCP 工具名和技能 ID。

## 下载和启动

普通 Windows x64 使用者选择 `QingGui-AI-0.2.0-windows-x64.zip`。完整解压到可写目录后，双击 `安装清规AI.cmd` 检查并创建桌面快捷方式；之后双击桌面入口或 `启动清规AI.cmd`。

包内已包含官方 CPython 3.14.4 嵌入运行时、35 个固定版本依赖和预构建界面。道路、横断面、地块与图则计算及 DXF 导出无需模型账号。自然语言模型接口为可选功能；实时 CAD 落图需要使用者自己的可用 AutoCAD，不随包分发。

网页采用默认浏览器显示，服务只监听本机。安装器不改系统 Python、全局执行策略或 CAD 注册。第三方包保留各自许可，依赖来源与摘要见包内 `runtime/DEPENDENCIES.json` 和 `THIRD_PARTY_NOTICES.md`。

## 本次实际验收

- 在本机含中文和空格的新目录中完整解压，使用随包解释器计算；解释器处于隔离模式。此记录不是第二台电脑的验证。
- 道路斜交示例生成 30 个实体，横断面示例生成 39 个实体；地块总图为 14 个实体，4 张独立图则分别为 20、20、21、20 个实体。
- 上述 7 份 DXF 独立回读均为米制（INSUNITS=6），DXF 审计错误和自动修复数均为 0。
- 地块示例有效边界为 42,300 m²，道路并集为 7,120 m²，净地块为 35,180 m²，面积平衡残差为 0。
- 桌面入口实际启动独立运行时；重复启动复用同一个服务进程。网页道路、横断面、地块总图和单地块图则分别检查。
- 便携包依据文件清单组装，源码不含个人数据；依赖摘要、ZIP 完整性和公开下载摘要另行核对。

修复后在独立运行时完成 **350 项测试通过**，有 1 项第三方测试客户端弃用提示。新增检查包括打包路径、技能迁移及 COM 缓存兼容。

实际 AutoCAD 2025 复测完成：新图总图 14 个实体，重复请求仍为 14，撤销回到 0，再写入 14；保存并重开仍为 14，INSUNITS=6。P001 图则的 20 个实体也成功保存。本次通过的是实体回读、操作和文件往返，未以此宣称所有 CAD 字体渲染、打印结果或其他厂商环境都已验收。

修复了 pywin32 makepy 缓存将部分属性暴露为不同大小写造成的落图失败。现在在 COM 调用边界统一包装返回对象，不删除用户的 COM 缓存。技能移动提供显式 `--relocate-from` 与完整备份；启动器将依赖检查和旧服务归属检查分开，复制目录不会接管原服务。

## 当前范围

这是原创的控规教学与方案绘图工作台。限定范围的道路、横断面、地块计算、指标表和图则可以实际生成；当前不等于湘源全功能复刻，也未完成同输入逐项等价对照。

尚缺完整真实场地自动选线、统一三模式路网设计、路网和断面关联更新、纸空间批量 PDF、真实地形纵断面、土方、管线，以及完整法定规划审查。默认数据为合成教学案例，不能作为北京大钟寺真实测绘成果。详见 [功能证据与验收清单](functional-coverage.md)。

没有安装 Windows 与所有 CAD 版本的兼容承诺。移动文件夹后的快捷方式和技能迁移步骤见 [Windows 使用说明](windows-portable.md)。
