# 当前几何能力和验收边界

道路平面由原创的解析偏移、路口图节点和圆弧相切计算产生。Shapely 只参与输出边界的离散闭合、面积、距离和碰撞校核。面积与约束距离涉及 qa_tolerance 的圆弧采样；CAD 中的圆弧保持真实 ARC/带 bulge 的 LWPOLYLINE。

支持独立直线、连续共线直线、独立圆弧；左右宽度按中心线段方向理解。0.1.1 支持同 level 的直路 T/X 平交（含斜交），并可整体旋转或平移。两条直路较小夹角的验证范围为 30–90°，等价于交角 30–150°；这是算法边界而非规范限值。T 口必须有连续直行主路，X 口必须是两条直路相交。junction_radius=0 明确表示尖角，不生成假圆弧。圆弧内侧偏移半径必须大于零。

不支持小于 30° 的较小夹角、Y/多岔口、圆弧路口、多段直线—圆弧复合线形、连续折线拐弯、连续道路突然变宽、同标高重叠中心线、没有支持节点的道路包络相交。宽度与角度组合使相切点反向时明确报 unsupported_offset_reversal，不把负修剪距离裁成零掩盖错误；路长不能容纳两端修剪时明确失败。大路网受 200 条道路、1000 段和每弧最多 4096 采样区间约束；这些是计算边界，没有吞吐量承诺。

units 标签不改变坐标数值。几何平面支持 m/mm/cm/ft/in，但真实 CAD 桥当前只接受米；真实转换需要同时缩放坐标、宽度、半径及容差。只接受声明 local_cartesian；不重投影经纬度或 EPSG 坐标。DXF 导入只接受平面 LINE/ARC/LWPOLYLINE；缺单位或宽度必须确认，非零 Z/倾斜 OCS 拒绝，DWG 不由此函数解析。

level 是连通性层号，不是高程；不同层不建立平交，不会输出桥梁或纵断面。明确 junction_type=unknown 的相交道路触发 needs_confirmation。为兼容旧输入，缺省 junction_type 暂按旧版 at_grade 处理；真实项目应显式填写，不能把历史默认当成已确认事实。direction、station_start、schema_version 目前是来源语义，尚无桩号标注算法。ROAD_EDGE 表示道路边界，不能据图层名推断规划红线或车行道。

preserve/no_build 多边形以道路完整包络校核；自交或零面积约束直接报错。更新案例 BLOCK_BOUNDARY 仅表示研究范围，不是已执行的用地边界约束。EXISTING_ROAD 是背景现状示意，保留道路和拟调整道路另有边线层；共同路口仍在 ROAD_JUNCTION。背景安全图层限定 CONTEXT、EXISTING_ROAD、BLOCK_BOUNDARY、RETAINED_OBJECT，其他名称归入 CONTEXT。

导出保留真实几何、单位、RoadSpec 元数据和中心线 ID。再次导入以 CAD 实際中心线读取结果为准；内嵌参数用于恢复宽度等设计参数。平面导入不能将横断面 DXF 当成道路中心线使用。导出不覆盖同名文件，出错方案不得导出成品。

横断面首版只支持连续路表、用户明确米单位、中心基准高程、逐侧组成顺序、宽度和向外横坡。CAD X 为偏距、Y 为高程，纵横比例 1:1，标注由真实 LINE/TEXT 构成，不是关联 DIMENSION。缺横坡不会默认零。组件 role 只提供语义，没有自动规范审查。台阶、缘石高差、结构层、地形、排水、土方、纵断面均未实现；输入已知不支持结构字段会拒绝，纵断面入口返回 needs_input。

实质测试覆盖：解析面积/相切、旋转平移、顺/逆时针弧与带符号 bulge 往返、单位显式缩放、零半径、短路段与宽度突变拒绝、断裂线形、相交形式未确认、保留对象碰撞、A/B 深复制隔离及 DXF 参数恢复；横断面覆盖两侧坡向、高程累加、组成顺序、缺值拒绝、米单位和真实 DXF 回读。真实 CAD 落图、修改和撤销证据由独立 CAD 验收记录给出。测试通过不等于工程规范合规，也不等于大量用户并发容量验证。
