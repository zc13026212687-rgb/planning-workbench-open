# Starter 0.3.1 发行记录

本版把实际使用过的控规技能整理为五个可移植目录，新增一键部署、只读诊断、课程流程与可选设计软件经验。版本关系：Starter 0.3.1 / CAD Native 0.3.0 / 计算引擎0.2.0。原生功能代码未修改，9个C#文件与原0.3.0源码逐个摘要一致。

## 客户端兼容范围

Codex：本机官方CLI注册路径及协议已测试；新AI会话中的技能发现与模型工具调用仍需用户重启后确认。Claude Code：目录和命令按当前官方文档/本机help核对，提供部署入口，但未执行真实Claude用户配置与模型会话的端到端测试。OpenClaw：提供技能+本地CLI部署；特定profile需要明确目录，本版不自动配置MCP节点。

部署回执的 `client_tools_discovered`、`cad_roundtrip_verified` 默认是 `not_tested`。这两个字段只由对应现场验收升级；安装退出0不替代宿主验收。

## 功能与资料边界

原生面板手动选线/边界命令尚未全覆盖，最终响应式布局修改缺逐像素复查。当前没有完整城市路网优化、竖向土方、管线综合或全部法定控规审查。内置案例均为合成教学数据，不能当作大钟寺测绘或规划批准文件。

原生0.3.0安装器在自定义过深目标目录的清洁安装测试中触发Windows路径长度限制；保留失败记录。默认APPDATA安装路径已通过本机部署校验，自定义目标应选择短路径。此限制未通过宣称“全部电脑安装通过”掩盖。

SketchUp、3ds Max、QGIS、ArcPy的历史经验另见 [可选工具](optional-design-tools.md)，没有把未核实许可的本地技能整包转发。三种设计方式为人机分工方案，不是已完成无人监督全自动设计的声明。
