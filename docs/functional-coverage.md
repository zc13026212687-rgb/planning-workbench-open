# 原创控规功能证据与验收清单

基线：清规AI · PlanningWorkbench Open 0.2.0；审阅日期：2026-10-13。仅核对本任务已有资料与验收记录，本轮未重跑产品测试或商业软件。

当前能够证明若干原创功能在限定输入和本机环境下可用；不能证明与湘源9.0的全功能、交互或输出等价。参考软件各能力目前仍属于**菜单/文档观察**，没有相同输入的算法运行对照。以下“已实测”只描述开放实现，不能转移为参考软件证据。

## “1:1”等价要求的最低证据

1. 固定参考软件精确版本、所依赖CAD版本、操作系统、插件配置与输入单位；记录已安装组件范围，不能以菜单数量作为功能分母。
2. 逐项定义相同输入、显式参数、前置CAD状态、具体动作与预期产物；使用原创或可公开许可夹具，不复制商业程序/素材/模板。
3. 记录参考软件实际输出和开放实现实际输出，保留版本、参数、输出哈希及独立读取结果；启动窗口、菜单可见和手册声明不能代替算法运行。
4. 分别比较几何/拓扑、数值/单位、对象语义/属性、交互改图/撤销、文件互操作、纸面比例与出图；容差和例外在运行前明确。
5. 包括正常、极限、非法输入、重复执行、变更及失败恢复用例；同输入不一致必须解释，未验证项保持未验证，不得靠静默修复贴近外观。
6. 若要声称更快或更稳定，另设相同任务和环境的重复测量；报告测量方法与原始时延/失败记录，不用主观打分。
7. “1:1功能等价”只能针对已界定且完成同输入对照的具体功能和版本；当前没有任何参考软件功能的完整对照记录，不能作全产品等价结论。
