# 源码与资料的打包边界

本项目自有代码、合成教学输入和技能文档采用根目录 MIT 许可。依赖遵守各自许可。建筑学长反编译产物、图标、商标、原程序文件均不包含在发行源代码中。

用户提供的京规研习数据库、施工图、图库 DWG、付费资料及其原始全文维持原位；本机只生成索引与少量分析证据。未明确再分发许可的来源不进入 GitHub 源码包。公开标准只提供官方链接、版本元数据和自有规则解释，不分发完整标准 PDF。两套资料的行业相关性不能证明它们满足北京当前规范。

打包脚本使用明确白名单，仅取自有 app、desktop 源文件、web 源码/锁文件、技能、合成样例、测试、公开出处目录、运行脚本和说明。不打包 data、.venv、node_modules、反编译分析、用户截图、个人绝对路径、server.json、数据库或 API 配置。源码测试夹具使用自有合成数据。

当前阶段交付可审查源码压缩包和独立技能包；尚未创建 GitHub 仓库或上传。发布时使用用户确定的账户、仓库名和可见性。不要将整个本地运行目录直接上传。
