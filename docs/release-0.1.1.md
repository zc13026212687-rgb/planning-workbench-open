# 0.1.1 道路平面增量

原有正交道路案例、更新案例和横断面保持兼容。本次增加两条直线道路斜交 T/X 路口，沿用同一独立几何引擎、桌面任务系统和 CAD 适配器；不依赖模型 API。

真实联调同时修复 CAD 面板的文档选择竞争问题：新图返回后直接锁定该 ID，等待刷新期间禁用 CAD 操作。目标图纸与当前活动图纸分别展示；活动图纸切换不自动重定向写入。只有显式选用且当前连接拥有写权限的图纸才能成为新目标。单独 UI 夹具验证了延迟创建和旧活动文档状态；真实 AutoCAD 分别完成 X/T 两幅新图，X 图修改、原生撤销与保存。

桌面：控规道路平面 → 方案对比 → 60°斜交 X 口 / 60°斜交 T 口 → 生成 → 查看夹角与几何校核 → 新建 CAD 文档落图。调整圆角后重新计算，再更新已落图方案；撤销和保存仍由 CAD 实际回读确认。

独立入口：`python planning_cli.py generate --case regulatory-road-plan --variant oblique-x60 --out 新输出目录`；只有加 `--cad-new` 才操作 CAD 新图。`cases` 可发现方案 ID，错误 ID 不会回退。

几何范围：较小夹角 30–90°；T 口带直行主路，X 口为两条直路相交。使用解析偏移交点、R·cot(θ/2) 相切距离和真实 ARC。对夹角越界、相切点反向、长度不足、未知交叉形式、Y/多岔口保留明确错误。这是实现与测试范围，不是规范推荐角度，也不保证所有宽度组合均可生成。

测试覆盖相切端点、法向宽度、解析道路面积、旋转平移、方向反转与左右宽交换、零半径、DXF 往返以及错误门槛。真实 CAD 和界面验收见本机 evidence/v011-* 记录；发布 ZIP 不包含本机任务、图纸或私人库。

曲线交叉口、连续曲直复合线形、纵断面、完整控规审批图集和真实 API 验收不因本次更新而视为完成。
