# 清规AI 技能清单与实测边界

本清单对应 **Starter 0.3.1**。入门包组织了 5 个技能入口，复用清规AI原创计算引擎，并提供 **CAD 原生插件 0.3.0** 的接入路线。目标是让使用者能够重做一次有输入、有校核、有可编辑成果的控规教学练习。

Skill 是给 AI 的操作说明和工具入口；计算引擎负责确定性几何；CAD 插件负责宿主内的面板、命令与实体。安装 Skill 不会自动安装 AutoCAD，也不等于已经连接 MCP 或完成真实 CAD 验收。安装入口与支持环境以[仓库首页](../README.md)为准。

## 首先安装哪些技能

| 技能 ID | 使用时机 | 交付内容与限制 |
|---|---|---|
| `qinggui-cad-workflow` | 第一次部署、准备课堂任务、串联完整操作流程 | 组织环境检查、输入确认、方案选择、生成校核、CAD 接入和成果回读；不替代设计者决定道路等级、真实控制指标或审批结论 |
| `beijing-regulatory-cad` | 整理任务书、规划依据和底图条件 | 记录来源、版本、单位、坐标与缺项；真实项目资料由使用者自行提供，包内教学输入不代表北京大钟寺测绘成果 |
| `planning-cad-road-plan` | 根据已有中心线绘制道路、限定 T/X 路口 | 调用原创道路几何引擎，保留参数、可编辑 DXF 与质量报告；复杂曲线路口、任意路网自动设计不在已验收范围 |
| `planning-cad-cross-section` | 已明确道路各部分宽度、次序与横坡 | 生成参数化路表横断面；不自动补造纵断面、结构层、排水、土方或缘石细节 |
| `planning-cad-regulatory-suite` | 已明确场地边界、道路走廊及地块指标 | 地块切分、面积平衡、指标表和基础单地块控制图则；计算道路走廊不自动等于法定红线，未知指标保持缺项 |

建议一次部署这 5 个入口，由工作流技能按任务调用其余技能。它们属于同一套工具链，不需要为每个技能单独安装一个 Python。安装时应按本机实际目录生成引擎定位信息，不能复制其他电脑的绝对路径。

需要在 CAD 内绘图时，再使用配套原生插件：当前明确验收对象为 **Windows x64 / AutoCAD 2025 R25.0 / .NET 8**。没有 AutoCAD 的使用者可以先做引擎计算和 DXF 导出；其他 CAD 产品和版本需要分别适配、编译和实测。

## 已经验证到哪一步

公开说明采用三个层次，避免把文件存在写成操作成功：

| 层次 | 判断依据 | 可以支持的结论 |
|---|---|---|
| 已安装 | 技能、引擎或插件文件存在，版本与路径能够解析 | 入口已部署；尚不能说明绘图成功 |
| 引擎验证 | 合成案例计算、参数校核、DXF 独立回读及相关测试通过 | 该案例能够生成规定输出；尚不能说明真实宿主或打印效果正确 |
| 宿主验证 | 指定 CAD 会话内实际生成实体，读取实体/参数，验证撤销、保存与重开 | 被验证的软件版本、操作和案例形成了可复核闭环 |

截至 2026-10-13，已有记录如下。这些是同一 Windows 工作站的实测及迁移检查，**不是多台电脑、全部 CAD 版本或全部操作路径的兼容认证**。

| 组件 | 记录中的实际结果 | 仍未覆盖 |
|---|---|---|
| 原创引擎 0.2.0 | 修复后 350 项测试通过；道路、断面、地块总图及图则 7 份 DXF 独立回读均为米制，DXF 审计错误与自动修复数均为 0 | 不能据此推定真实场地参数正确或满足完整规划规范 |
| 地块教学例子 | 有效边界 42,300 m²，道路并集 7,120 m²，净地块 35,180 m²，面积平衡残差 0 | 数据为原创合成教学输入，不能作为任何真实地段的测绘或审批依据 |

## 三种参与方式如何使用同一套工具

1. **AI 起草**：输入确定的边界、约束与参数，AI 整理结构化方案。生成结果仍须通过几何校核和设计者审阅；当前不承诺任意真实地段一键自动完成路网设计。
2. **AI 提供备选，人选择**：分别保存方案参数与预览，由人确认采用方案后进入细化。方案各自保留版本，不能混用不同方案的地块编号和控制指标。
3. **人画中心线，AI 辅助细化**：在 CAD 内绘制或选择中心线，输入道路宽度等已知参数，再生成边界、横断面与地块成果。

这三种方式是课程组织与人机分工方式，不代表本版本已经提供完整的统一“三模式自动路网设计器”。当前已实现的命令和参数范围以实际插件与引擎说明为准。

## 公开包包含什么

原创技能、工作流说明、规划引擎、原生插件及安装脚本采用项目根目录的 [MIT 许可](../LICENSE)。合成案例可以随项目分享。Python 运行时和依赖保留各自许可、版本、来源和摘要；项目 MIT 许可不覆盖第三方材料。

公开包不收集使用者整机技能、模型账号或配置，也不附带商业 CAD/GIS 主程序、授权文件、付费插件、第三方素材库、私人底图与课程原件。历史上使用过的软件不必全部安装。SketchUp、3ds Max、QGIS 和 ArcGIS 的分工与证据见[可选设计工具经验指南](optional-design-tools.md)。

本地存在的第三方技能如未定位完整许可和上游版本，只提供来源说明或原创经验指南，不直接复制进入本包。发布时使用明确文件清单，不能把整个运行目录或用户技能目录直接提交到 GitHub。
